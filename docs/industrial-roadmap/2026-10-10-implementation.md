# 2026-10-10 工业模拟工位与网关实施记录

本次在视频保存点 `16f90f5` 上新增独立 `industrial_station/`，未修改原视频代码或 720p 摄像头参数。所有设备动作与输入均为 **SIMULATED**，没有连接电机、限位开关、电流传感器、PLC 或 GPIO。

## 已交付

- PyModbus 3.15.0 模拟往复执行机构，MANUAL/AUTO 模式与动作状态机。
- 原子命令块、启动标识、会话、截止时间、序号去重、单一网关租约和本地看门狗。
- 独立 Modbus 网关，数据质量/心跳检查、断线撤权、恢复后显式授权，不自动重发运动。
- HTTP 只读/操作角色令牌、命令审计、SQLite 事件、JSON 测试报告及 PowerShell 演示入口。
- 缺失限位、双限位冲突、慢动作、Modbus busy、心跳冻结等模拟故障。

未交付：完整 HMI、视频报警快照/回放关联、多操作员账户仲裁、真实电气接线、实体机构控制、传感器标定。角色令牌不是完整账户体系，HTTP 仅限可信局域网。

原计划模拟器放 PC，本次为便于常驻演示先在 Pi 独立进程部署。PC 通过 Wi-Fi 调用网关，Modbus 本身走 Pi 回环；不能把本次实验写成跨机 Modbus 的无线链路性能验证。

100 次测试执行窗口约为 UTC 03:56 至 03:57（北京时间 11:56 至 11:57），PC 经 Wi-Fi 发出每次指令并查询结果。对报告原始命令独立复算后，成功数、均值、最近秩 P95 与汇总一致。失败/UNKNOWN 不会被自动剔除后再补跑成“100 次成功”。

最终部署前还修复了一个跨会话边界问题：旧动作完成记录的序号与新会话序号可能重合。授予新会话时清除旧完成记录，并新增模型和真实 Modbus 集成回归，避免新动作被旧结果误判为完成。

## 部署与演示

Pi 路径：`/home/eur/industrial-lab`，独立服务 `pi-industrial-simulator` 和 `pi-industrial-gateway` 已启用开机启动。模拟器仅监听 `127.0.0.1:5020`；网关局域网 `:8091`。原 `pi-signaling` 与视频容器保持运行。

健康入口：[http://192.168.3.19:8091/health](http://192.168.3.19:8091/health)，只返回 JSON，不是新增的可视化操作面板。原视频入口：[http://192.168.3.19:8080/](http://192.168.3.19:8080/)。

电脑仓库目录下运行：

```powershell
.\industrial_station\lab.ps1 status
.\industrial_station\lab.ps1 demo --cycles 10
.\.venv\Scripts\python.exe -m industrial_station.acceptance
```

最后一个命令会主动进行模拟故障测试，不是只读查询。详细的手动动作、故障编号、寄存器表、鉴权、测量边界与回退方法见 [模块 README](../../industrial_station/README.md)。

配置令牌、数据库与运行目录不入 Git；只归档无凭据的模拟命令和视频计时数据，不保存摄像头画面。部署前版本保存在 Pi 私有 staging 目录，可停止新增服务回退；不停止或改动视频服务。
